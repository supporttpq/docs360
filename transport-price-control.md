# Transport Price Control

{% hint style="warning" %}
Ensure departure stat weeks are defined for each selected year. See [Departure stat weeks](setup/departure-stat-weeks.md).
{% endhint %}

### Overview

The **Transport Price Control** screen provides detailed statistics about transport bookings, occupancy, load factors, and profitability. It helps you analyze transport performance over time. It also supports pricing, capacity, and route decisions.

### Purpose

Use this screen to:

* Track booking activity within a defined period
* Monitor demand, occupancy, and load factor across different transports and hotels
* Identify performance variations, such as load-factor changes, web clicks and views, and profitability
* Compare booking trends, views and clicks, and revenue contribution to support pricing decisions

### Preconditions

Before using **Transport Price Control**:

* Ensure bookings and departures exist within the selected timeframe.
* Ensure the relevant agency or department provides departure statistics.
* Use transport periods no older than 12 months.
* Ensure your permissions allow access to reporting and statistical data.

### Instructions

#### Step 1: Set filters

Use the available filters at the top of the screen to refine the report:

* **Booking start / Booking end** – Define the booking date range for the report
* **Departure from / Departure to** – Select the departure date range
* **Arrival from / Arrival to** – Filter by arrival location
* **Views/Clicks start / Views/Clicks end** – Set ranges for online activity, including views and clicks
* **Pax no** – Search by passenger number
* **User Owners / Transports / Hotels / Status** – Use **Edit** to include or exclude specific elements
* **All bookings** – Select whether to display all bookings or apply a filter

#### Step 2: Apply filters

* Click **Display** to generate the report.
* Click **More filters** to adjust filters.
* Click **Clear** to reset filters.

#### Step 3: Review results

The report displays data in multiple tabs, including:

* **Capacity** – Transport capacity statistics
* **Regulation Rules** – Applied business rules affecting transport
* **Occupancy** – Percentage of seats filled
* **Vacancy** – Remaining available capacity
* **Load Factor / Variation** – Measures of occupancy efficiency and changes
* **Load Factor Variation %** – Percentage variation in load factor over time
* **WEB Views/Clicks/Pax** – Online interest and conversion data
* **Average Profit** – Profit per booking or transport
* **Single Transport Profit Flow** – Profitability analysis for individual transports

#### Step 4: Interpret results

If no results are shown, the system provides a message indicating possible reasons:

* Departure statistics are missing for the selected period or agency.
* Selected departures exceed the 12-month range.
* No results match the applied filters.

### Result

The system generates transport-related performance statistics for pricing, performance, and profitability assessment.
