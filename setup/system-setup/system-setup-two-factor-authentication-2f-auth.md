# System Setup – Two-Factor Authentication (2F Auth)

### Overview

**2F Auth** configures two-factor authentication for Tourpaq Office users. It extends the username-and-password login with a verification code.

This setting works with user-profile contact data and company-wide [System Setup](./) security controls.

{% hint style="warning" %}
Enabling 2FA can prevent login when contact data is incorrect.

Validate contact data and test with a pilot user before activation.
{% endhint %}

### Purpose

Use **2F Auth** to require an additional identity check after password authentication.

The available factors are SMS, email, and an authenticator app.

### Requirements

Before enabling 2FA, confirm these requirements:

* Administrator access to **System Setup**.
* Valid phone numbers for **Authenticate with SMS**.
* Valid email addresses for **Authenticate with Email**.
* An enrolled authenticator app for **Authenticate with an Authenticator App**.
* A pilot user for testing the selected methods.

### Navigation

In Tourpaq Office, open **Setup → System Setup → 2F Auth**.

The page provides one selection for each available second-factor method.

### Field descriptions

| Field                                      | Description                                                                                                                               |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **Authenticate with SMS**                  | Enables SMS verification codes at login. This method requires a valid mobile phone number in each user profile and a working SMS service. |
| **Authenticate with Email**                | Enables email verification codes at login. This method requires a valid email address in each user profile.                               |
| **Authenticate with an Authenticator App** | Enables codes generated by an authenticator app. Each user must enroll the app before using this method.                                  |

### Configuration steps

To enable two-factor authentication:

1. In **System Setup**, open **2F Auth**.
2. Validate user contact data for each selected method.
3. Select **Authenticate with SMS**, **Authenticate with Email**, or **Authenticate with an Authenticator App**.
4. Test the selected methods with a pilot user.
5. Communicate the activation and setup process to affected users.

### System behavior

After 2FA is enabled, Tourpaq requires a selected second factor after password authentication.

**Authenticate with SMS** sends a code to the mobile number in the user profile. **Authenticate with Email** sends a code to the email address in the user profile.

**Authenticate with an Authenticator App** uses a code generated in the enrolled app. Tourpaq can offer another enabled verification method when one is available.

### Examples

#### Email verification

Enable **Authenticate with Email** when every affected user has a validated email address. Tourpaq sends the login code to that address.

#### Authenticator app verification

Enable **Authenticate with an Authenticator App** after users enroll their apps. Users enter the generated code after password authentication.
