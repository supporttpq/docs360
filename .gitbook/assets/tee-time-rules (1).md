# Tee Time Rules

**Applies to:** Tourpaq Office · **Last reviewed:** 2026-09-14

Golf courses commonly cap how many tee times a passenger can hold, restrict
online sale to certain weeks of the season, or stop sale a set time before
the round. **Tee Time Rules** is where you record those limits for a single
Teetime product.

### Overview

**Tee Time Rules** is a section on a Teetime product's **Basic setup** tab.
It controls how many times the product can be booked, which weeks and hours
it can be booked in, how its price is calculated, and whether it needs
manual confirmation. The section only appears when the product's **Extras
Category** is set to `Teetime`.

### Purpose

Use Tee Time Rules to:

* Cap how many times a passenger, or the allotment as a whole, can book this
  tee time.
* Restrict sale to the first weeks of the season, or stop sale before a
  fixed hour on the day of play.
* Show sunrise and sunset times when a customer selects this tee time, or
  reuse allotment generated by another product.

### Preconditions

* The Extras product exists and its **Extras Category** is set to
  `Teetime`.
* You know the golf course's own booking limits and cut-off times, so the
  values you enter match its policy.

### How-to

{% stepper %}
{% step %}
**Open the product**

Go to **Extras**, open the Teetime product, and select the **Basic setup**
tab.

{% hint style="info" %}
**TO VERIFY** — confirm the exact left-navigation label and path to the
Extras list in the current build (the sidebar in this review was icon-only,
with no visible text labels).
{% endhint %}
{% endstep %}

{% step %}
**Open the section**

If **Tee Time Rules** is collapsed, click its header (or **Open all** above
the setting panels) to expand it.
{% endstep %}

{% step %}
**Set the rules**

Fill in the fields described in [Field Reference](#field-reference) below,
then click **Save**.
{% endstep %}
{% endstepper %}

The limits apply to new bookings of this tee time as soon as you save.

### Field Reference

<figure><img src="/files/ID" alt="The Tee Time Rules section on a Teetime product's Basic setup tab, showing Pax limit, Latitude, Longitude, Product Parent ID, TeeTime Pin, Only first week(s), Limit Per Day, Limit before hour, First available price and Requires confirmation"><figcaption>The Tee Time Rules section on a Teetime product's Basic setup tab.</figcaption></figure>

| Field | Description | Required | Notes |
| --- | --- | --- | --- |
| **Pax limit** | Sets the maximum number of times this tee time can be booked for each passenger. | No | `How many times this product can be booked for each passenger (per interval)`. **TO VERIFY** — what "interval" refers to here (for example, per tee time slot or a separately configured scheduling interval). |
| **Latitude** | Sets the geographic latitude Tourpaq uses, together with **Longitude**, to calculate sunrise and sunset times shown when a customer selects this tee time. | No | `Latitude and Longitude are used if you want to display sunrise and sunset when selecting TeeTime`. Leave blank if you don't need sunrise/sunset shown. |
| **Longitude** | Sets the geographic longitude used, together with **Latitude**, to calculate sunrise and sunset times. | No | Shares its tooltip with **Latitude**; both fields must be filled in for sunrise/sunset to display. |
| **Product Parent ID** | Points this product at the numeric ID of another Extras product, so this tee time reuses that product's generated allotment instead of creating its own. | No | `Fill Product ID when you want to use generated allotment from another Product`. Numeric field. |
| **TeeTime Pin** | Displays the PIN code Tourpaq has generated for this tee time product. | No | Read-only text field. Click the refresh icon next to it to generate a new PIN, then click **Save** — the new PIN is not kept until the product is saved: `Shuffle the pin-code to a new one. Save Extra is required to save the new pin!` |
| **Only first week(s)** | Restricts sale of this tee time to its first 1–4 weeks. Leave it at `--------` for no restriction. | No | `Allow to select TeeTime only on first [n] week(s)`. **TO VERIFY** — what week 1 counts from (for example, the allotment start date or the product's period/trip length). |
| **Limit Per Day** | Sets the maximum number of allotments of this tee time that can be booked in a single day. | No | `How many allotments can be booked per day` |
| **Limit before hour** | Sets a second, stricter booking limit for the period before a fixed time of day. Enter the booking count in the left field and the cut-off time (24-hour, `hh:mm`) in the right field. | No | `How many times this product can be booked before selected hour (per interval)`. Click **×** to clear the cut-off time. **TO VERIFY** — same "interval" question as **Pax limit**. |
| **First available price** | When enabled, Tourpaq sells every tee time on this product at the price of the first available tee time, rather than pricing each booking individually. | No | `First available price is the selling price for all tee times (per booking)` |
| **Requires confirmation** | When enabled, a booking of this tee time is not confirmed automatically. | No | No tooltip is shown for this field in the product. **TO VERIFY** — the exact confirmation workflow: what status the booking receives, who confirms it, and whether the customer or supplier is notified. |

{% hint style="warning" %}
**TeeTime Pin** is not saved by the refresh icon alone. If you shuffle the
PIN and leave the page without clicking **Save**, the product keeps its
previous PIN.
{% endhint %}
