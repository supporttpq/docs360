# Conversations

Guests can write to the guides of their destination from the Guest App. Conversations is where those chats are listed for guides in the Guide App, and the **Customer chat** window is where Tourpaq Office users see the same chats.

### Overview

**Conversations** is one of the ten sections on the [Guide App](file:///guest-app/guide-app.md) Home screen. It lists the guest chats that a guide can follow, grouped into three list types: **My conversations**, **Untaken conversations** and **Other conversations from the same destination**.

A conversation belongs to one booking. It starts when a guest sends a message from the **Chat** section of the **Guide** tab in the [Guest App](file:///guest-app/visit-sun-app.md).

Tourpaq Office shows the same chats in two places:

* The **Customer chat** window, opened from the chat icon in the top bar. It has three tabs: **Admin Conversation**, **Destination Conversations** and **My conversations**.
* The **Conversations** tab of a booking. See [Conversation](file:///booking/new-booking/conversation.md).

Conversations is not SMS, a push notification or a booking comment. It is the chat between a guest and the guides or Tourpaq Office users.

### Purpose

Use Conversations to:

* See which guests have written to the destination and which chats nobody has picked up.
* Identify the booking, guest name, hotel and resort behind a chat.
* Review the message history of a booking in Tourpaq Office.

### Preconditions

* The guest has a booking and uses the [Guest App](file:///guest-app/visit-sun-app.md). Guests sign in with the booking number.
* The guest has sent at least one message from **Chat**. Without a message there is no conversation.
* For the Guide App: the guide has a Tourpaq user and signs in as described on [Guide App](file:///guest-app/guide-app.md). The guide is assigned to the resort of the booking through a [guide team](file:///guides.md).
* For Tourpaq Office: a user who can open the chat icon and the booking.

The Guest App shows this notice at the top of the **Chat** screen (Danish):

```
Vores chat er åben 7 dage før afrejse - men du kan kontakte os på info@example.dk
```

It reads: "Our chat is open 7 days before departure – but you can contact us at info@example.dk."

### How-to

#### Conversations in the Guide App

{% stepper %}
{% step %}
**Open Conversations**

1. On the **Home** screen, tap **Conversations**. Inside another section, tap the burger icon at the top left and then tap **Conversations**.
2. The **Conversations** screen opens with the **SELECTED LIST TYPE** field at the top.
{% endstep %}

{% step %}
**Choose a list type**

1. Tap the **SELECTED LIST TYPE** field.
2. In the **Types of conversations** window, tap **My conversations**, **Untaken conversations** or **Other conversations from the same destination**.
3. To leave the window without choosing, tap **Close**.
4. The list shows the conversations of the chosen type. When there are none, the screen shows **No conversations**.

<figure><img src="../../.gitbook/assets/imagesguide-app-types-of-conversations (2).png" alt="Types of conversations window listing the three list types" width="375"><figcaption></figcaption></figure>

<figure><img src="../../.gitbook/assets/conversation1.jpg" alt="Conversations screen with My conversations selected and the text No conversations" width="375"><figcaption></figcaption></figure>

<figure><img src="../../.gitbook/assets/imagesguide-app-other-conversations-empty (2).png" alt="Conversations screen with Other conversations from the same destination selected and No conversations" width="375"><figcaption></figcaption></figure>
{% endstep %}

{% step %}
**Check which booking a conversation belongs to**

1. Find the conversation in the list. Each row shows the guest name and the booking number, for example `Name Surname - 773524`.
2. Tap the information icon at the right of the row.
3. Read the booking details, then tap **Ok**.

<figure><img src="../../.gitbook/assets/imagesguide-app-untaken-conversations (2).png" alt="Untaken conversations list with one conversation row and an information icon" width="375"><figcaption></figcaption></figure>

<figure><img src="../../.gitbook/assets/imagesguide-app-conversation-info-popup (2).png" alt="Information window showing booking number, hotel, resort, agency, adults and children"><figcaption></figcaption></figure>
{% endstep %}

{% step %}
**Open a conversation and chat with the guest**

1. Tap the guest name in a conversation row. Do not tap the information icon.
2. The chat opens. The guest name is at the top of the screen and the message history is below it.
3. Type your message in the field at the bottom of the screen and tap **Send**.
4. To add a picture, tap **Media**, then tap **Choose a picture** or **Take a picture**. To close the window without adding a picture, tap [**Cancel**](#user-content-fn-1)[^1].

When you open a conversation from **Untaken conversations**,[ ](#user-content-fn-1)[^1]it is moved from **Untaken conversations** to **My conversations.**

{% endstep %}
{% endstepper %}

#### Conversations in Tourpaq Office

{% stepper %}
{% step %}
**Open Customer chat**

1. Click the chat icon in the top bar, left of your user name. A red number on the icon shows how many conversations are unread.
2. In the **Customer chat** window, click **Admin Conversation**, **Destination Conversations** or **My conversations**.

<figure><img src="../../.gitbook/assets/imagesoffice-chat-icon-dashboard (2).png" alt="Tourpaq Office dashboard with an arrow pointing at the chat icon showing a red number 4"><figcaption></figcaption></figure>

<figure><img src="../../.gitbook/assets/imagesoffice-customer-chat-admin-conversation (2).png" alt="Customer chat window with the Admin Conversation tab selected and two unread conversations"><figcaption></figcaption></figure>
{% endstep %}

{% step %}
**Read the list**

Under **Unread conversations**, find the booking in the table. The columns are **BOOKING**, **BRAND**, **NAME**, **HOTEL**, **RESORT**, **ADULTS**, **CHILDSNO**, **UNREAD**, **LAST MESSAGE DATE** and **TAKEN BY**.

<figure><img src="../../.gitbook/assets/imagesoffice-customer-chat-destination-conversations (2).png" alt="Customer chat window with the Destination Conversations tab selected and one unread conversation"><figcaption></figcaption></figure>
{% endstep %}

{% step %}
**Open the chat**

Click the speech bubble icon at the start of the row. A **Chat - Booking No** window opens at the bottom right of the screen. It shows the messages of the booking and the label `- unread` under a message that has not been read.

<figure><img src="../../.gitbook/assets/imagesoffice-chat-window-booking-782502 (2).png" alt="Chat window for booking 782502 opened from the speech bubble icon, with one unread message and a Send button"><figcaption></figcaption></figure>
{% endstep %}

{% step %}
**Review the full history on the booking**

1. In the **BOOKING** column, click the booking number.
2. In the booking, open the **Conversations** tab.

<figure><img src="../../.gitbook/assets/imagesoffice-booking-conversations-tab (2).png" alt="Conversations tab of booking 782502 with one message and empty READ DATE and TAKEN BY columns"><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

The **Conversations** tab lists every message of the booking with **SENT DATE**, **FROM**, **MESSAGE**, **READ DATE** and **TAKEN BY**. A message from the guest shows the booking number in **FROM**.

#### How a guest message is routed

Routing is described on the [Guest App](file:///guest-app/visit-sun-app.md) page:

| Guest situation                          | Who receives the message                                                           |
| ---------------------------------------- | ---------------------------------------------------------------------------------- |
| The booking is in the future.            | All guides and admin users. The first guide who answers picks up the conversation. |
| The guest is already at the destination. | All guides on the resort of the booking.                                           |

### Field Reference

#### Guide App

| Field                                             | Description                                                                              |
| ------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| **SELECTED LIST TYPE**                            | Chooses which conversations the screen lists. Tap it to open **Types of conversations**. |
| **My conversations**                              | List type.                                                                               |
| **Untaken conversations**                         | List type.                                                                               |
| **Other conversations from the same destination** | List type.                                                                               |
| **Close**                                         | Closes **Types of conversations** without changing the list type.                        |
| Conversation row                                  | One conversation: the guest name and the booking number, separated by a dash.            |
| Information icon                                  | Opens the booking details of the conversation.                                           |
| **No conversations**                              | Text shown when the chosen list type has no conversations.                               |

#### Tourpaq Office: booking Conversations tab

| Field         | Description                            |
| ------------- | -------------------------------------- |
| **SENT DATE** | Date and time the message was sent.    |
| **FROM**      | Sender of the message.                 |
| **MESSAGE**   | Text of the message.                   |
| **READ DATE** | Date and time the message was read.    |
| **TAKEN BY**  | The Tourpaq user who took the message. |

The **Customer chat** window lists unread conversations. Whether a read conversation stays in the list is not confirmed.
{% endhint %}
