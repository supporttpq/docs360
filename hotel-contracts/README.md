# Hotel Contracts

## Hotel Contract List

### Overview

The Hotel Contract List provides a centralised overview of all hotel contracts in the system. It enables users to quickly locate contracts, monitor their status, and access individual contract details.

### Purpose

Use this page to:

* Monitor the status of hotel contracts, including imported, accepted, and rejected contracts.
* Search and filter the list to quickly find specific hotels or contracts.
* Open individual contracts to review their details or make updates, where permitted.
* Remove contracts from the list when they are no longer required.

### Preconditions

Before using the Hotel Contract List, ensure that:

* Contracts have been created or imported into the system using the appropriate process.
* All hotels referenced in the contracts have been created and are available in the system.
* You have the necessary user permission to view, edit, or delete contracts, as applicable.

***

### Instructions

#### Accessing the page

To access the Hotel Contract List, navigate to Hotel → Hotel Contracts in the main menu.

#### Filtering contracts

Use the filters at the top of the list:

* **Contract Name**
* **Hotel Name**
* **Hotel Code**
* **Created Date**
* Toggle **Show Hidden** to include hidden contracts

Click **Display** to apply filters or **Clear** to reset.

#### Reading the table

Each row displays:

* **Contract Name** – Click to open the contract
* **Hotel Name** – As defined in the system
* **Hotel Code** – The internal code for identification
* **Created Date** – When the contract entry was created
* **Imported** – Whether the contract came from an import
* **Created User** – Who created the contract entry
* **Accepted / Rejected** – Review status, if used in your workflow
* **Rejected Comment** – Reason for rejection, if applicable
* 🗑️ **Delete** – Removes the contract entry from the list

{% hint style="warning" %}
**Important:** Deleting a hotel contract permanently removes the contract from the system, including its previous import record. However, the hotel first created or imported in connection with the contract is retained and is not deleted. If you need to import the same contract again, you must first recreate the contract before you can reimport it.
{% endhint %}

#### Creating a new contract

Click the **Create** button in the upper-right corner to initiate a new contract entry.
